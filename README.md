# AML Transaction Monitoring & KYC Risk Analytics

An end-to-end financial crime analytics project using SQL, Python and Power BI,
built on fully synthetic data.

## Business problem
Financial institutions must monitor customer activity, assess risk and keep KYC
records current. This project simulates that workflow: detecting suspicious
transaction patterns, scoring customer risk, and reporting operational MI.

## Tech stack
PostgreSQL | Python (pandas, SQLAlchemy, rapidfuzz, scikit-learn) | Power BI
